# Cibus

Cibus is a mobile-first SvelteKit client for Loyola College's Eat Right food court.

## Development

```sh
cp .env.example .env
npm ci
npm run dev
```

`DEV_MODE=true` selects the in-memory Eat Right adapter, so login and ordering flows work without contacting the college site. Any non-empty credentials are accepted in fixture mode.

## Commands

```sh
npm run check   # Svelte and TypeScript diagnostics
npm test        # module-interface tests
npm run build   # production Node build
```

## Architecture

The server has one deep module at `src/lib/server/eatright/`. Route files are intentionally one-line adapters:

```ts
export const GET = eatRight.handler("account");
```

The module's interface is `handler(endpoint)` plus the synchronous `isConnected(cookies)` check used by server layouts. Its implementation hides session encryption, session renewal, scraping, upstream headers and cookies, parsing, caching, search fan-out, order grouping, payment, and history confirmation.

The true external seam is `EatRightRemote`. Production uses the HTTP/Cheerio adapter; development and tests use the in-memory fixture adapter. Composition happens once in `src/lib/server/eatright/index.ts` with ordinary factory DI—there is no DI container.

```text
src/lib/server/eatright/
├── index.ts       composition root and public exports
├── module.ts      interface implementation and workflows
├── contract.ts    domain types and the upstream seam
├── upstream.ts    production HTTP/Cheerio adapter
├── fixture.ts     development/test adapter
└── session.ts     encrypted HttpOnly session codec
```

Placement rules:

- Route files translate filesystem routing only; no upstream logic belongs there.
- Eat Right URLs, JSP fields, headers, cookies, and parsers belong in `upstream.ts`.
- User workflows, validation, caching, and error presentation belong in `module.ts`.
- Add a new seam only when there are at least two justified adapters.
- Test behavior through the module interface rather than private functions.

## Production

Set a strong `SESSION_SECRET` and leave `DEV_MODE` unset or false. The Node adapter output is generated by `npm run build`.
